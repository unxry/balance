Контент сверялся с перечисленными первоисточниками 19.10.2026. Инженерный отчёт оформлен 20.10.2026. Это проверка существования страниц и соответствия общих утверждений, **не независимая медицинская экспертиза**. Перед представлением системы как клинически валидированной требуется проверка зарегистрированным диетологом/врачом.

В приложении нет персональных норм, обещаний темпа, лечения плато или автоматического уменьшения калорий. Примеры еды — авторские иллюстрации, без вымышленных КБЖУ. Пороговые параметры алгоритма — инженерная эвристика, не медицинские нормы.

## Что осталось для экспертной проверки

- Клиническая редактура RU/EN, применимость для уязвимых групп и согласованность межъязыковых формулировок.
- Проверка численных порогов и ошибок классификатора на независимой реальной выборке, с пропусками, разными весами и источниками измерений. Текущие синтетические тесты проверяют поведение программы, а не клиническую точность.
- Периодическая повторная проверка источников при выпуске новых рекомендаций. Приложение работает офлайн; открытие внешней страницы требует интернет-соединения.
- По одному дневнику невозможно надёжно оценить полноту питания, причины изменений веса и индивидуальные противопоказания. Нельзя считать это подтверждением дефицита.
