20.10.2026. Продолжение build 22 (`266703c`), без установки на физический iPhone.

- **150 активных практических планов:** 137 универсальных, 13 контекстных.
- **95 добавлено, 5 дублей объединено.** 55 прежних активных текстов сохранены; пять выведенных текстов продолжают читаться в истории. Все 200 ID build 22 сохраняют RU/EN, версию и смысл отметки выполнения. Всего 295 разрешаемых ID, включая 145 алиасов; эти числа не используются для подсчёта уникальных планов.
- **127 тем ротации, 119 универсальных.** Близкие действия сгруппированы, даже когда контекст оправдывает отдельный план.

## Содержание и проверка смысла

До расширения проверены все 60 исходных планов: задача, действие, контекст, ограничения, альтернативы, источники и RU/EN. Объединены `macros-02 → meal-lunch`, `nutrition-09 → today-15`, `activity-02 → today-07`, `food-fibre → nutrition-01`, `meal-dinner → meal-lunch`. Пять прежних текстов и тексты их прежних алиасов сохранены, поэтому старое выполнение не становится выполнением другого действия.

Новые сценарии: обед без холодильника и безопасная перевозка, столовая, общий стол, сменный график, разные предпочтения семьи, доступность еды, конкретные способы приготовления, замены с учётом ограничений, доступная активность, хранение заготовок, организация сна, удобная ёмкость для питья, ошибки единиц/числа/даты и границы фактов/прогноза. Общие варианты бутерброда и блина с той же начинкой не включены; вместо них — самостоятельные задачи гигиены и разморозки.

Обе локализации сверены по действию, шагам, альтернативе и критерию. Новым 95 планам присвоена версия 5 и уровень `practicalIdea`; они не представляются клинически доказанными назначениями. Шесть профильных источников проверены 20.10.2026, прежние 14 сохраняют свою дату проверки. Выдуманных КБЖУ, личных норм, обещаний похудения и объяснений причин стабильного веса не добавлено.

Поштучный [аудит](DAILY_TIPS_31_AUDIT.md), [проверка похожих сценариев](daily_tips_semantic_review.json) и [машинный каталог](daily_tips_catalog.json) содержат действия, контексты, обе локализации, ограничения и правила применимости. Каталог воспроизводится командой `dart tool/export_daily_tips_catalog.dart` и сверяется с исполняемыми данными тестом. Авторская смысловая проверка не заменяет независимую редакторскую и клиническую экспертизу. Клиническая проверка алгоритма возможного плато по-прежнему не завершена.

## Ротация и ограничения

Сохранены дата назначения, сериализация операций и Hive `dailyTipsV1`. Смена языка, контекста или перезапуск не меняют уже назначенный совет и явно выбранную альтернативу. Чтение, избранное и выполнение остаются независимыми действиями.

Исправлен порядок выбора: после 60-дневного исключения ID и связанных тем смена категории имеет приоритет перед ещё не показанными статьями. Это устраняет серии большой категории, когда доступна другая категория. Если остальные категории не проходят окно, приоритет остаётся у исключения близких действий.

Для неполного дневника в каждом проверенном профиле доступно **137 универсальных планов / 119 тем** после реальных фильтров: возраст неизвестен, несовершеннолетие, подтверждённый взрослый возраст, беременность, лактация, риск РПП и медицинское ограничение. Неполные записи не становятся полным рационом; отсутствующий сигнал не создаётся ради персонализации.

Два прогона реального каталога по **500 дней** проверяют ID и темы в предыдущих 59 календарных днях (расстояние повторов не меньше 60 дней), соседние повторы, смену категории при доступной альтернативе, охват универсальных планов и перезапуски. Режимы: персонализация выключена; включена с одним неполным днём питания. Отдельный ограниченный пул из трёх планов проверяет конечный fallback и честный размер `eligiblePlans`.

Это не безусловная гарантия отсутствия повторов: большое число явных выборов, другой репозиторий или будущие ограничения могут исчерпать свежие темы. Тогда сервис использует доступный старый контент, избегая соседнего повторения при наличии выбора. Пользовательский явный выбор не блокируется 60-дневным окном. Будущие даты при переводе часов считаются недавними, как прежде.

## Совместимость и проверка

Публичная фикстура build 22 проверяет все 200 прежних ID и точное равенство обеих локализаций. Для каждого из пяти выведенных планов проверено восстановление избранного, исходного задания, выбранной альтернативы, причин выбора и выполнения версии 4 без записи в хранилище. Исходные резервные копии и личные базы не открывались и не изменялись; тесты используют временные синтетические Hive-данные.

Визуальные тесты закрепляют прежнее назначение `meal-dinner`, чтобы расширение каталога не подменяло проверяемый экран. Один эталон детализации обновлён для существующего уведомления архивной статьи; остальные визуальные эталоны сохранены.

Результаты итогового прогона приведены в [TEST_RESULTS](TEST_RESULTS.md). Release: `lib/main.dart`, `1.0.0+23`, подпись проверяется `codesign --verify --deep --strict`. Приложение не устанавливалось на физический iPhone.
