# Аудит практической пользы Daily Tips 3.0

Проверены все 80 статей предыдущего каталога в RU/EN. Итог: 60 самостоятельных практических планов, 20 объединённых тем. Все 200 разрешаемых ID сохранены (60 активных + 140 алиасов). Количество не увеличивалось ради ротации.

## Критерии и способ проверки

Для каждого активного плана проверены: ясная задача на сегодня; одно основное действие; два-три шага; применимый пример; простой/доступный вариант; проверяемый человеком критерий выполнения; объяснение пользы без обещаний; отсутствие выдуманного личного наблюдения. Наличие глагола или длина строки сами по себе не считаются доказательством пользы.

Все RU/EN пары отредактированы по одному сценарию: одинаковое основное действие, смысл примера, ограничения и критерий. Репрезентативные случаи ниже проверены отдельно по ожидаемому бытовому результату. Источники поддерживают общий принцип; варианты блюд и действия — практические иллюстрации, не клинически проверенные назначения.

## Что не считается выполнением

Открытие карточки, выбор другой статьи, открытие дневника и сохранение не ставят отметку выполнения. Чекбокс — явная самоотметка пользователя; это не независимая проверка сделанного. Библиотека создаёт выбор на день только после явной кнопки «Выбрать на сегодня». Старые выполнения показываются как отметки прежней версии текста.
